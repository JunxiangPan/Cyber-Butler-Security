# CBP v0.1.2 - The Zero-Trust Quality Gate for AI-Generated Code

CBP is a fail-closed quality gate designed to verify that AI or humans did not
fake coverage, tamper with evidence, or ship unvetted binaries.

### 9 Strict Gates

This release ships with 9 active gates that block the release pipeline if
violated:

- Encoding: rejects GBK, Windows-1252, and UTF-8 BOM.
- Coverage: enforces distinct thresholds for core logic and security paths.
- Dependency: requires strict version pinning and SHA256 hashes.
- Comments: rejects slop comments and generic boilerplate docstrings.
- Docs: binds documentation hashes to prevent silent deletion.
- Claims: matches Release Notes against the CI-generated manifest.
- Binary: requires `.build.json` and SBOM for large binaries.
- Custom: evaluates regex/literal rules from `custom_rules` (warn by default).
- Upgrade: runs configured upgrade evidence and rejects unapproved schema breaks.

### Immutable Evidence Chain

The release assets attached to this tag are generated by the dogfood job:

1. `quality-manifest.json` is generated by running the gates in real time.
2. The file is pinned to this specific CI `run_id` and `commit_sha`.
3. The SHA256 of the manifest is uploaded alongside it.
